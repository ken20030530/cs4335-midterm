Lecture 1 · W01 L1-26.pdf

Euler Circuit

Euler circuit

一個 circuit 每條邊剛好用一次，頂點可以重複經過。
屬於 P：有 polynomial-time algorithm。

Hamiltonian cycle

一個 cycle 每個頂點剛好經過一次，最後回到起點。
Decision problem 是 NP-complete。

Lecture 用這兩題說明一個重點：兩個問題描述看起來差不多，複雜度可以完全不同。

必背 Theorem

A connected graph has an Euler circuit if and only if every vertex has even degree.

Parallel edges 要分開計，每條都要走一次，也各自計入 degree。

證明（英文，考試照寫）

(⇒) Necessity. Going through the circuit, each time a vertex is visited we enter by one edge and leave by another, so its degree increases by 2. Hence every vertex has even degree.

(⇐) Sufficiency. Suppose G is connected and every vertex has even degree.

  1. Whenever the walk enters a vertex v (other than the start), there is an unused edge to leave v, because deg(v) is even.
  2. So the walk eventually returns to the starting vertex and forms a circuit C.
  3. If no vertex on C has an unused edge, C is an Euler circuit (G is connected).
  4. Otherwise, pick a vertex v on C with an unused edge. In the unused edges every degree is still even, so we can build another circuit C′ from v and merge C′ into C.
  5. Repeating this, every edge of G is used.

Algorithm

1. Start at any vertex with nonzero degree; follow unused edges until
   returning to the start. This forms a circuit C.
2. If C contains every edge, return C.
3. Otherwise choose a vertex v on C incident to an unused edge. From v,
   form another circuit C' using only unused edges.
4. Merge C' into C (at v) and repeat from Step 2.

Slides 例子：C1 = a→b→c→a，C2 = b→d→e→f→b，在 b 合併得 C3 = a→b→d→e→f→b→c→a；再加 C4 = e→i→j→h→c→g→e，最後 C = a→b→d→e→i→j→h→c→g→e→f→b→c→a。答案不唯一。

下面檢查器預設就是這一題：按「下一步」逐步看每個 circuit 怎樣走、怎樣合併。圖中把第三個小 circuit 叫 C3（即 slides 的 C4），合併後的統稱 C。

Euler circuit 檢查器每條邊寫兩個字母，例如 ab，或 a-b
常見陷阱
  • 要同時寫兩個條件：connected 和 每個 degree 是 even。
  • 地圖題：每個區域是頂點，每條共同邊界是一條邊。Slides 例子 deg(A)=2、deg(B)=3、deg(C)=2、deg(D)=3，所以沒有 Euler circuit。
  • 「每個省份剛好經過一次再回到起點」是 Hamiltonian circuit，不是 Euler。
  • Hierholzer 的 O(|V|+|E|) 實作和 adjacency list／matrix 屬於 Fun／Not tested。

Greedy：Interval Scheduling 與 Partitioning

Greedy algorithm 每一步都揀當下最好的選擇。要想出一條規則很容易，難的是證明它一定 optimal，考試的 Hard 分就在證明。

Interval Scheduling：最多可以做幾份 job

Job j 由 sj 開始、fj 結束；兩份 job 不重疊就是 compatible。目標是揀出最多份互相 compatible 的 job。

錯的規則
  • Earliest start：(0,10), (1,2), (3,4) → 揀了 (0,10) 就只有 1 份，最優是 2 份。
  • Shortest job：(0,5), (4,6), (5,10) → 揀了 (4,6) 只有 1 份，最優是 (0,5), (5,10)。
  • Fewest conflicts：同樣有反例（見 slides p.10）。
正確規則

Earliest finish time first：按 f 由小到大排序，跟之前已選的 compatible 就選。

Sorting O(n log n) + 掃描 O(n) = O(n log n)

INTERVAL_SCHEDULE
1. Sort the jobs so that f1 ≤ f2 ≤ ... ≤ fn.
2. A ← ∅; let j* be the last selected job.
3. for j = 1 to n:
       if A = ∅ or s_j ≥ f_j*:  A ← A ∪ {j};  j* ← j
4. return A

證明：Exchange argument

Let G = i1, …, ik be the greedy solution and OPT = j1, …, jm an optimal solution, both sorted by finish time, so m ≥ k. Assume i1 = j1, …, ir = jr and ir+1 ≠ jr+1.

Greedy picks the compatible job that finishes earliest, so ir+1 finishes no later than jr+1. Replacing jr+1 with ir+1 in OPT keeps all jobs compatible and keeps the size m, so we get another optimal solution that shares r+1 jobs with G.

Repeat until OPT = i1, …, ik, jk+1, …, jm. If m > k, job jk+1 starts after ik finishes, so greedy would have selected it, a contradiction. Hence m = k and G is optimal.

注意：要證明的是 |G| = |OPT|，不是 G = OPT（optimal solution 可以有很多個）。

Interval Partitioning：最少要幾間課室

必背

Depth = 同一時間最多有幾堂重疊（open intervals）。任何安排都需要 至少 depth 間課室。

Greedy：按 start time 由小到大排序；放入任何一間可以容納的現有課室，放不下才開新課室。用 priority queue 記每間課室最後一堂的 finish time，O(n log n)。

證明：Structural bound

Let d be the number of classrooms the greedy algorithm allocates. Classroom d is opened because lecture j cannot be held in any of the first d−1 classrooms. Since lectures are processed by start time, each of those d−1 classrooms holds a lecture that starts no later than sj and finishes after sj. Together with j, d lectures overlap at time sj, so d ≤ depth. Every schedule needs at least depth classrooms, so greedy is optimal.

Interval Lab格式：(s,f),(s,f),…；結束時間 = 下一份開始時間算 compatible

Tutorial 1 Exercise 3 · 不用交
Selecting breakpoints：沿固定路線由 Princeton 開車去 Palo Alto，沿途有油站，滿油可以走 C。目標是停最少次加油。Greedy：go as far as you can before refueling（能走多遠就走多遠，走不到下一個油站之前才加油）。理解這個 greedy，並證明它 optimal。

答案

Proof (greedy stays ahead). Let g1 < … < gp be the greedy stops and f1 < … < fq the stops of an optimal solution. Claim: gr ≥ fr for every r. For r = 1, f1 is within C of the start and greedy picks the farthest such station, so g1 ≥ f1. If gr ≥ fr, then fr+1 − gr ≤ fr+1 − fr ≤ C, so fr+1 is reachable from gr and greedy goes at least as far: gr+1 ≥ fr+1. The destination is within C of fq ≤ gq, so greedy needs no stop after gq, i.e. p ≤ q. Hence greedy is optimal.

中文版（意思一樣）：設 greedy 停的油站是 g1 < … < gp，最優方案停的是 f1 < … < fq。要證每一站 gr ≥ fr。

  1. 第一站：f1 一定在起點 C 範圍內；greedy 揀 C 範圍內最遠的油站，所以 g1 ≥ f1。
  2. 下一站：如果 gr ≥ fr，則 fr+1 − gr ≤ fr+1 − fr ≤ C：對手的下一站離 greedy 更近，greedy 一定開得到；greedy 揀開得到的最遠站，所以 gr+1 ≥ fr+1。
  3. 終點：終點在 fq 的 C 範圍內，而 gq ≥ fq 離終點更近，greedy 由 gq 直接到得了終點，不用再停，所以 p ≤ q，greedy 是 optimal。

Minimum Spanning Tree

  • Tree：connected 且沒有 cycle。n 個頂點的 connected graph 是 tree ⇔ 有 n−1 條邊。
  • Spanning tree：包含所有頂點的 tree。MST：總重量最小的 spanning tree。
  • Cut (S, V−S)：把頂點分成兩邊。一條邊兩端在不同邊就是 crossing；crossing 邊中最輕的叫 light edge。
  • Edge set A 是 good：A 包含在某個 MST 裡。加入後 A 仍然 good 的邊叫 safe edge。
必背 Cut Property

Let A be good and (S, V−S) a cut that no edge of A crosses. Then any light edge crossing the cut is safe for A.

證明

Let ℓ = (u, v) be a light edge crossing the cut, and T an MST containing A.

  1. If ℓ ∈ T, then A ∪ {ℓ} ⊆ T, so ℓ is safe.
  2. Otherwise, adding ℓ to T creates exactly one cycle.
  3. The path in T from u to v must cross the cut at another edge ℓ′ on this cycle.
  4. No edge of A crosses the cut, so ℓ′ ∉ A. Since ℓ is light, w(ℓ) ≤ w(ℓ′).
  5. T′ = T − {ℓ′} + {ℓ} is a spanning tree containing A ∪ {ℓ}, and w(T′) = w(T) − w(ℓ′) + w(ℓ) ≤ w(T). So T′ is also an MST, and ℓ is safe for A.
Kruskal

A 是一個 forest。所有邊由輕到重排序；邊的兩端在不同 component 就加入，否則拒絕（會形成 cycle）。選夠 |V|−1 條就停。

用 disjoint set（MAKE_SET／FIND_SET／UNION）檢查 cycle。
O(|E| log |E|)

Prim

A 是一棵 tree，由 root r 開始。每步加入離開 tree 最輕的邊，即 cut (S, V−S) 的 light edge。

Priority queue 記 key[v]、parent[v]。
Binary heap O(|E| log |V|)；Fibonacci heap O(|E| + |V| log |V|)

兩個 algorithm 每步揀的都是「一個沒有被 A 跨越的 cut 的 light edge」，所以都是 generic MST algorithm 的特例，正確性都來自 cut property。

MST 逐步示範藍 = 已選；橙 = 這一步的邊；紅虛線 = 拒絕
圖：
常見陷阱
  • 題目問「indicate the order」就要寫加邊次序，例如 AD(1), CF(1), CE(2), …。
  • 重量相同時次序可以不同，MST 也可能不止一個。Lecture 圖總重是 22。
  • Challenge：所有重量都不同時 MST 唯一；把 min 換成 max，Kruskal 和 Prim 都可以求 maximum spanning tree。

Shortest Path：Dijkstra 與 Boat Rescue

  • δ(u, v) = 最短路徑的重量；沒有路就是 ∞。有 negative-weight cycle 時最短路徑可能不存在。Dijkstra 假設所有 w(e) ≥ 0。
  • Optimal substructure：最短路徑的 subpath 也是最短路徑（否則換成更短的 subpath 會得到更短的路）。
  • d[v]：目前找到的最短長度；π[v]：路徑上 v 的前一個頂點。用 π 由終點倒推（backtracking）得出路徑。
RELAX(u, v, w)
  if d[v] > d[u] + w(u, v)
      d[v] ← d[u] + w(u, v);   π[v] ← u

DIJKSTRA(G, w, s)
  d[s] ← 0;  for each v ≠ s: d[v] ← ∞, π[v] ← NIL
  S ← ∅;  Q ← V                      // priority queue keyed by d
  while Q ≠ ∅
      u ← EXTRACT-MIN(Q);  S ← S ∪ {u}
      for each v ∈ Adj[u]:  RELAX(u, v, w)
Dijkstra 表格示範頂點旁邊的數字是 d；藍 = 已在 S；黃 = 這一步取出

Correctness（歸納法，考試照寫）

Claim. At any time, for each v ∈ S, d[v] is the length of a true shortest s–v path. Induction on |S|. Base: |S| = 1, d[s] = 0. Step: assume it holds for |S| = k, and the algorithm adds v with the smallest d[v]. Let P be any s–v path, and x the last node of P in S.

Case 1 (x is right before v): w(P) ≥ d[x] + w(x, v) ≥ d[v], by relaxation.

Case 2 ((x, y) is the first edge of P leaving S, y ≠ v): w(P) ≥ d[x] + w(x, y) ≥ d[y] ≥ d[v], since relaxation gives d[y] ≤ d[x] + w(x, y), the algorithm chose the smallest d so d[y] ≥ d[v], and the remaining edges are non-negative.

So no path is shorter than d[v].

Running time

Array：EXTRACT-MIN O(|V|) × |V| 次 + |E| 次 relax → O(|V|²)

Heap：每次 EXTRACT-MIN／更新 O(log |V|) → O(|E| log |V|)，sparse graph 較快

Negative edge 反例

s→u = 2，s→v = 1，u→v = −10。Dijkstra 先定 d[v] = 1，但 s→u→v = −8 更短。

Boat Rescue（Lecture 4 尾段）

每隻船最多載 2 人，載重上限 W。求最少船數。

Greedy

排序後用兩個 pointer：最重的人配最輕的人，wl + wr ≤ W 就一齊上船，否則最重的人獨自一船。O(n log n)。

Case 1: wl + wr > W. Since wl is the lightest, wr + w > W for every other w, so wr must go alone in every feasible solution.

Case 2: wl + wr ≤ W. If OPT pairs (wr, wk) and (wl, wm), exchange to (wr, wl) and (wk, wm). This is feasible since wm ≤ wr gives wk + wm ≤ wk + wr ≤ W, and the boat count is unchanged. Remove the pair and apply induction.

例子：[30, 40, 60, 70]，W = 100 → {30, 70}、{40, 60}，共 2 隻船。可以在 L5 的 Greedy Lab 試其他數字。

Greedy 更多例子

Fractional Knapsack

n 件物品 (wi, vi)，背包上限 W kg。Fractional 版本可以只拿一部分。

Greedy

計 unit price vi/wi，由高到低拿；最後一件放不下就拿一部分。

Assume distinct unit prices (merge items with equal unit price). An optimal X must satisfy P1: its total weight is W; P2: no item outside X has a higher unit price than an item in X. If X differs from greedy at item i, replacing part of a cheaper item k by the same weight of i increases the value (exchange argument). The greedy solution is the only one with P1 and P2, so it is optimal.

0–1 knapsack 不能用 greedy

W = 20：a($10, 10kg)、b($10, 10kg)、c($12, 11kg)。Greedy 拿 c 得 $12，最優是 a + b 得 $20。

Scheduling to Minimize Lateness

Job j 需要 tj 時間，deadline dj。Lateness ℓj = max{0, fj − dj}，目標是令最大 lateness L = max ℓj 最小。

正確：Earliest Deadline First

按 dj 由小到大排，一份接一份做，中間不留空檔。O(n log n)。

錯的規則

Shortest processing time：t = (1, 10)、d = (100, 10) → 先做 1 令 job 2 遲 1。
Smallest slack d−t：t = (1, 10)、d = (2, 10) → 先做 2 令 job 1 遲 9。

證明：Inversion + adjacent swap

  1. There is an optimal schedule with no idle time; the greedy schedule has no idle time.
  2. An inversion is a pair i, j with di < dj but j scheduled before i. Greedy has no inversions. If a schedule with no idle time has an inversion, it has one between two adjacent jobs.
  3. Swapping an adjacent inverted pair (j, i) reduces the number of inversions by one. Other jobs are unaffected, ℓ′i ≤ ℓi, and if ℓ′j > 0 then ℓ′j = f′j − dj = fi − dj ≤ fi − di = ℓi. So the maximum lateness does not increase.
  4. Starting from an optimal schedule, keep swapping until no inversion remains. The result is the greedy schedule and it is still optimal.

Minimize Average Waiting Time（2022 Q6）

一部機做 n 份 job，job 的 waiting time = 排在它前面所有 job 的 processing time 總和。

Greedy

Shortest Job First (SJF)：按 pi 由小到大做。O(n log n)。

Let OPT be an optimal schedule. If OPT has no inversion (a job with larger p before a smaller one), OPT = SJF. Otherwise there is an adjacent inversion Ja, Jb with pa > pb. Swap them: other jobs' waiting times are unchanged; w′(Jb) = w(Ja) and w′(Ja) = w(Ja) + pb < w(Ja) + pa = w(Jb). So the total waiting time does not increase and the number of inversions drops by one. Repeating, OPT becomes SJF, so SJF is optimal.

Slides 例子：p = 3, 4, 1, 8, 2, 6。原本次序 total = 0+3+7+8+16+18 = 52；SJF 次序 J3, J5, J1, J2, J6, J4 → 0+1+3+6+10+16 = 36。

Divide and Conquer

三步

Divide：拆成同類但更細的 subproblems。Recur：遞迴解每個 subproblem。Conquer：合併答案。

Merge Sort

mergeSort(S)
  if S.size() > 1
      (S1, S2) ← partition(S, n/2)      // Divide   O(1)
      mergeSort(S1);  mergeSort(S2)     // Recur    2T(n/2)
      S ← merge(S1, S2)                 // Conquer  O(n)

T(n) ≤ T(⌈n/2⌉) + T(⌊n/2⌋) + n，T(1) = 0 → T(n) = O(n log n)。

展開法（n = 2k）

T(n) = n + 2T(n/2)
     = 2n + 2²T(n/2²)
     = 3n + 2³T(n/2³)
     = … = kn + 2^k T(n/2^k)
n/2^k = 1 ⇒ k = log₂n
T(n) = n log₂n + nT(1) = O(n log n)

Telescoping（T(1) = 0）

T(n)/n = T(n/2)/(n/2) + 1
       = T(n/4)/(n/4) + 1 + 1
       = …
       = T(1) + 1 + … + 1   (log₂n 個)
       = log₂n
⇒ T(n) = n log₂n

Iteration Method 例子：T(n) = 4T(n/2) + n

T(n) = 4T(n/2) + n
     = 4²T(n/4) + 2n + n

     = 4^k T(n/2^k) + n(2^k − 1)
n = 2^k ⇒ 4^k = n²

Counting Inversions

排名 a1, …, an 中，i < j 但 ai > aj 就是一個 inversion。暴力檢查所有 pair 要 Θ(n²)。

Sort-and-Count(L)
  if L has one element: return (0, L)
  divide L into halves A and B
  (rA, A) ← Sort-and-Count(A)
  (rB, B) ← Sort-and-Count(B)
  (r,  L) ← Merge-and-Count(A, B)       // A, B sorted
  return (rA + rB + r, L)
Merge-and-Count 規則

合併兩個已排序的 A、B 時，每當從 B（右半）拿出元素，就加上 A 中剩下的元素數目，因為它們全部比這個元素大。合併 O(n)，所以 T(n) = 2T(n/2) + O(n) = O(n log n)。

D&C 設計題

題目常常規定 function prototype，例如 x, y = f(low, high)，array 作 global variable；只傳 low、high，不要複製 array，否則做不到 O(n)。

(1) 找最大值（Tutorial 5 Q1）

f(l, h, A)
  if l == h: return A[l]
  m ← ⌊(l + h) / 2⌋
  a ← f(l, m, A);  b ← f(m+1, h, A)
  return max(a, b)
T(n) = 2T(n/2) + c  ⇒  O(n)

(2) 最大和第二大（2022 Q5，n 個不同數字）

f(low, high)                      // returns (largest, second largest)
  if low == high:      return (A[low], −∞)
  if high == low + 1:  return (max(A[low],A[high]), min(A[low],A[high]))
  mid ← ⌊(low + high) / 2⌋
  (x1, y1) ← f(low, mid)
  (x2, y2) ← f(mid+1, high)
  if x1 > x2: return (x1, max(y1, x2))
  else:       return (x2, max(x1, y2))
Comparisons: g(n) = 2g(n/2) + 2
           = 2^k g(n/2^k) + 2(2^k − 1)  ⇒  g(n) = O(n)

合併時第二大只可能是「贏家那邊的第二大」或「輸家那邊的最大」，所以只需 2 次比較。2022 官方答案把四個數放入 array 再排序，同樣是 O(1)，也拿全分。

(3) Maximum subarray sum（Tutorial 5 extra）

在 mid 切開，最優 subarray 一定是三種之一：全在左邊、全在右邊、跨過 mid。跨過 mid 的那個由 mid 向左掃找最大後綴和、由 mid+1 向右掃找最大前綴和，相加即可，O(n)。所以 T(n) = 2T(n/2) + O(n) = O(n log n)。

例子 A = [−2, 1, −3, 4, −1, 2, 1, −5, 4] → 最大和 6，subarray [4, −1, 2, 1]，即 index 4 至 7（由 1 開始數）。

Hard 分的關鍵

證明模板

Midterm 的證明幾乎都是以下四種之一。先認出用哪一種，再套句式。

1 · Exchange argument

用於：interval scheduling、interval cover（T4）、fractional knapsack、boat rescue。圖解：Interval scheduling 的 exchange

Let G = g1, g2, … be the greedy solution and OPT = o1, o2, … an optimal solution. Suppose they agree on the first r choices and gr+1 ≠ or+1. By the greedy rule, gr+1 is [at least as good as] or+1, so replacing or+1 with gr+1 keeps OPT feasible and does not make it worse. We obtain an optimal solution that agrees with G on r+1 choices. Repeating this, we get an optimal solution identical to G. Hence G is optimal.

2 · Inversion / adjacent swap

用於：minimize lateness（EDF）、minimize waiting time（SJF）。圖解：EDF 的 adjacent swap

Take an optimal schedule (with no idle time). If it has an inversion, it has an adjacent inversion. Swapping the two adjacent jobs does not change the other jobs, reduces the number of inversions by one, and does not increase the objective. After finitely many swaps we reach the greedy schedule, which is therefore optimal.

3 · Structural bound

用於：interval partitioning（depth）。圖解：2022 Q1(b)(c) 最後一步的 depth

Every solution needs at least B (e.g. depth). The greedy algorithm uses at most B, because it only opens a new resource when B items overlap. So greedy is optimal.

4 · Cut property ／ Induction

用於：MST（cut property：換邊 T′ = T − ℓ′ + ℓ）；Dijkstra（對 |S| 歸納，分兩個 case）。全文見 L3、L4。圖解：cut property、Dijkstra 兩個 case。

證明常見扣分
  • 只寫「greedy is locally optimal so it is globally optimal」，沒有比較 OPT。
  • 寫 G = OPT。正確是：存在一個 optimal solution 可以變成 G，或 |G| = |OPT|。
  • 交換後沒有說明為何仍然 feasible，以及為何不會變差。

Degree：a 2、b 3、c 4、d 3、e 2。b、d 是 odd，所以沒有。加一條 bd（parallel edge），全部變 even，就有 Euler circuit。在 Euler 檢查器 加入 bd 試試。
